# AI-Based Image Classification & Object Detection

## Project Overview
This project aims to develop an AI-powered computer vision system that performs image classification and multi-object detection using deep learning.

## Technologies
- Python
- PyTorch
- Torchvision
- YOLO26n
- OpenCV
- NumPy
- Pandas
- Scikit-learn
- Streamlit

## Models
- MobileNetV3 – Image Classification
- YOLO26n – Object Detection
